## Installing Git on Windows
### Step 1 : Download Git for windows
- Go to https://git-scm.com/downloads/win 
- Select the package suitable for your system
### Step 2 : Run the Installer
- Open the downloaded `.exe` file .

	![](https://raw.githubusercontent.com/cybercena/Static-assets/refs/heads/main/Git_and_Github/windows3.png)
	
	
	
	
	

- Click Next through the steps, and choose recommended options:
![](https://raw.githubusercontent.com/cybercena/Static-assets/refs/heads/main/Git_and_Github/windows4.png)


![](https://raw.githubusercontent.com/cybercena/Static-assets/refs/heads/main/Git_and_Github/windows7.png)


![](https://raw.githubusercontent.com/cybercena/Static-assets/refs/heads/main/Git_and_Github/windows10.png)


### Step 3 : Finish Installation 

![](https://raw.githubusercontent.com/cybercena/Static-assets/refs/heads/main/Git_and_Github/windows11.png)

- After installation , open **Git Bash** or **Command Prompt**
- verify installation:
```bash
git --version
```

![](https://raw.githubusercontent.com/cybercena/Static-assets/refs/heads/main/Git_and_Github/windowsbash.png)



## Installing Git on Linux
### Step 1: Update your Package lists:

```bash
sudo apt update
```

{% hint style="tip" %}
**Do you know ?:** you don't need to use sudo command, if you are a root user.
{% endhint %}

![](https://raw.githubusercontent.com/cybercena/Static-assets/refs/heads/main/Git_and_Github/linux1.png)

### Step 2 : Install Git:

```bash
sudo apt install git
```

![](https://raw.githubusercontent.com/cybercena/Static-assets/refs/heads/main/Git_and_Github/linux2.png)
### Step 3 : Verify installation:

```bash
git --version
```

![](https://raw.githubusercontent.com/cybercena/Static-assets/refs/heads/main/Git_and_Github/linux3.png)
